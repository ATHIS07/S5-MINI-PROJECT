AWS API Gateway & CORS Cheatsheet

Required backend response headers

To connect without browser CORS blocks, ensure your Lambda / API Gateway returns:

Access-Control-Allow-Origin: *
Access-Control-Allow-Headers: Content-Type,Authorization,x-api-key
Access-Control-Allow-Methods: GET,POST,PUT,PATCH,DELETE,OPTIONS
  • Enable Mock Integration on OPTIONS preflight routes.
  • Return status code 200 with empty body on OPTIONS.
  • Lambda exceptions must include CORS headers in error responses.
